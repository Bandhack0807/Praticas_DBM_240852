Lee el mapa como una red

Cada tarjeta es una tabla. PK identifica una fila y FK guarda una referencia. Una FK conecta con la PK o índice único indicado en el inspector. Las cardinalidades muestran el máximo que permite el DDL; no afirman que haya filas presentes.

Usa el laboratorio para mover registros simulados por las referencias. No se cargan ni modifican datos reales.
